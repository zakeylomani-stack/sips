GitHub One-Click Uploader

Choose files, enter your repository details, and upload them directly to GitHub.

1. Connect to your repository

Create a fine-grained token in GitHub Settings → Developer settings → Personal access tokens. Limit it to this repository and grant Contents: Read and write.

Security: this page sends the token directly from your browser to api.github.com. It is not uploaded to your repository or saved by this page. Use a token limited to one repository, and revoke it after use if it is temporary. Do not use this uploader on a shared/public computer.

2. Choose files

To preserve folders, choose files individually and enter their paths below only if needed. Existing files with the same path will be updated.

No files selected.

How it works: uploads each selected file through GitHub's Contents API, creating or updating it in the chosen branch. Large files may exceed GitHub's API limits.
